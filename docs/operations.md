# Operations support

ADP ships [CI/CD](../product/adp/ci-cd/workflow.md), [deployment](../product/adp/ci-cd/deployment.md), [ops setup](../product/adp/ops-setup.md), and [monitoring](../product/adp/monitoring.md) policies with their task skills. They guide agents in preparing project-owned configuration and carrying out authorized checks.

ADP itself supplies no daemon, scheduler, provider adapter, credentials, or hosted CI service. Each project selects tools, environments, commands, thresholds, owners, and recovery targets. Repository checks, hosted CI, alert delivery, deployment, and recovery are distinct verification claims.
