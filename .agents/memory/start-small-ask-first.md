Don't start working right away, and don't propose large changes. Start small, think through what's actually needed, and ask the user for more context before building or writing a full proposal.

**Why:** The user asked for an architecture agent. I built a full skill without asking, then wrote up a long proposal. They wanted neither.

**How to apply:** When given a new piece of work, first ask short questions about scope and intent. Propose the smallest next step only after the user answers. Ask one question at a time. Don't ask anything the repo's conventions already answer (e.g. plans go in `plan/`). Decide those yourself and state them.
