# ADP skills

ADP-owned catalog. Use the linked skills for matching requests; project overrides belong in `AGENTS.md`.

| Skill | When to use |
|---|---|
| [adp-architecture](../skills/adp-architecture/SKILL.md) | Design or revise system boundaries, data ownership, dependencies, and shared technical decisions before program design. |
| [adp-code-review](../skills/adp-code-review/SKILL.md) | Independently review a scoped implementation or combined candidate for correctness, meaningful tests, and agreement between requirements, code, and documentation. |
| [adp-coding-rules](../skills/adp-coding-rules/SKILL.md) | Apply ADP coding conventions when writing, changing, or reviewing code alongside the project's own language and formatting rules. |
| [adp-completion](../skills/adp-completion/SKILL.md) | Verify feature or scoped change completion against acceptance, independent review, evidence, and reconciled documentation. |
| [adp-git](../skills/adp-git/SKILL.md) | Commit scoped changes, open or update a pull request, or merge an authorized validated candidate into a named branch using the project Git workflow. |
| [adp-implement](../skills/adp-implement/SKILL.md) | Diagnose and fix a bug or implement an authorized scoped change, verify affected behavior, and reconcile documentation using proportional planning. |
| [adp-maintain](../skills/adp-maintain/SKILL.md) | Review and apply an authorized installed ADP update or scoped pipeline cleanup while preserving project-owned instructions, skills, memory, and settings. |
| [adp-monitor](../skills/adp-monitor/SKILL.md) | Inspect a named environment, alert, incident, or service/agent run with bounded read-only evidence and no implicit remediation. |
| [adp-ops-setup](../skills/adp-ops-setup/SKILL.md) | Design or configure project-owned CI/CD, Git protection, deployment, recovery, and monitoring facilities for an explicitly scoped target. |
| [adp-program-design](../skills/adp-program-design/SKILL.md) | Design changed components, contracts, state, invariants, interactions, and failure behavior within established architecture before implementation. |
| [adp-release](../skills/adp-release/SKILL.md) | Prepare a release and assess release readiness, qualify or publish it, deploy an authorized candidate, or recover a named environment using project commands and immutable identities. |
| [adp-security-code-review](../skills/adp-security-code-review/SKILL.md) | Audit a PR or named change for security defects and produce the required security report before general code review. |
| [adp-setup](../skills/adp-setup/SKILL.md) | Integrate installed ADP with project instructions and existing Claude rules/skills; establish project context, stack checks, and authorized host configuration without overwriting project ownership. |
| [adp-test](../skills/adp-test/SKILL.md) | Select, implement, or run scoped unit, integration, contract, end-to-end, UI, performance, mutation, and static checks against project requirements and candidate gates. |
| [adp-ui-ux](../skills/adp-ui-ux/SKILL.md) | Design, implement, or evaluate web/native interfaces against user tasks, accessibility, existing visual direction, and explicit acceptance criteria. |
| [adp-vulnerability-search](../skills/adp-vulnerability-search/SKILL.md) | Test explicitly authorized isolated staging targets for exploitable weaknesses, verify security fixes, and report bounded runtime security evidence. |
